## 무엇을 취소하려는지 적기

앱에서 구매한 상품을 취소하려는지, 외부 상대와 나눈 지급 약속을 중단하려는지 적습니다. 두 문제가 함께 있다면 문의를 나누세요. 주문번호와 외부 대화의 접수 번호도 섞어 쓰지 않습니다.

## 각각의 조건 확인하기

구매 환불은 상품과 결제 조건에 맞는 공식 정책을 읽습니다. 외부 정산은 실제로 안내받은 중단 조건을 확인하세요. 이 원고는 개별 계약의 효력이나 거래의 적법성을 판정하지 않습니다.

## 처리 결과를 두 줄로 남기기

구매 요청의 접수·승인·반영 상태를 적고, 외부 상대의 답변과 실제 지급 내역을 별도로 적습니다. 취소라고 쓰인 메시지만으로 모든 금전 관계가 정리되었다고 판단하지 마세요.

## 두 처리를 한 표에서 분리하기

아래는 실제 사례가 아닌 기록 예시입니다. 구매 환불 요청은 제출했지만 외부 지급은 확인되지 않은 경우, 구매는 접수 상태이고 외부 정산은 미확인 상태라고 적습니다. 어떤 한쪽의 취소 메시지를 두 처리의 완료 표시로 쓰지 않습니다.

| 처리 대상 | 요청한 내용 | 실제 확인 결과 |
| --- | --- | --- |
| 콘텐츠 주문 | 해당 구매의 환불 요청 | 접수 / 결정 / 반영 확인 |
| 외부 지급 약속 | 중단 조건과 금액 확인 | 상대 답변 / 실제 내역 / 미확인 |
