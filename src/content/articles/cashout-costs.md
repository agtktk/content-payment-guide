## 비교표에 넣을 네 가지 금액

견적을 받을 때는 구매 금액, 입금 예정액, 별도 공제액, 청구 예정액을 같은 표에 적습니다. 입금 예정액이 공제 전인지 후인지도 표시하세요. 조건이 구두로만 전달되면 나중에 어떤 금액에 합의했는지 확인하기 어렵습니다.

## 가상 예시: 비율보다 차액 보기

아래는 실제 거래가 아닌 산술 예시입니다. 결제 청구액이 100,000원이고 입금 약속이 80,000원이라면 차액은 20,000원입니다. 별도 비용 3,000원이 입금액에서 공제되는 가정에서는 최종 수령액이 77,000원이 되어 차액은 23,000원입니다.

| 항목 | 가상 금액 |
| --- | --- |
| 결제 청구액 | 100,000원 |
| 공제 전 입금 약속 | 80,000원 |
| 별도 공제 | 3,000원 |
| 최종 수령액 | 77,000원 |
| 청구액과 수령액 차이 | 23,000원 |

비교 차액 = 청구액 − 최종 수령액. 차액 비율 = 비교 차액 ÷ 청구액 × 100. 이 가정의 차액 비율은 23%이며, 법정 수수료나 업체의 공시 요율이 아닙니다.

## 견적 확인 질문

- 입금 약속은 모든 공제를 반영한 최종 금액인가요?
- 미입금·일부 입금·거래 중단 시 구매 대금은 누가 부담하나요?
- 구매한 콘텐츠가 제공되지 않거나 환불이 거절되면 어떤 절차가 있나요?
- ‘추가 결제하면 기존 돈을 돌려준다’는 조건이 붙어 있나요?

## 청구와 환불 기록을 함께 보관

입금 캡처 하나만으로 전체 거래를 설명할 수는 없습니다. 최초 제안, 합의 금액, 구매 영수증, 실제 입금과 환불 상태를 시간 순으로 묶어 두면 서로 다른 금액이 발생한 지점을 찾기 쉽습니다.
