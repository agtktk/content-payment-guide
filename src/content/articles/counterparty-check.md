## 누가 무엇을 답했는지 남기기

사이트 주소, 상담 이름, 연락 경로, 조건을 안내한 시각을 적습니다. 검색 광고와 실제 상담에서 이름이 달라지면 이유를 물으세요. 비슷한 이름이나 같은 로고를 사용한다는 사실만으로 동일 주체라고 판단하지 않습니다.

## 확인 자료의 의미 구분하기

상대가 제시한 등록 정보나 화면은 해당 공식 조회 경로에서 확인할 수 있는지 살펴봅니다. 자료가 있다고 해서 지급 능력이나 개별 거래의 결과까지 증명하는 것은 아닙니다. 확인하지 못한 자격은 미확인으로 남깁니다.

## 금전 조건은 별도 확인하기

상대의 신원을 설명받았더라도 최종 금액, 지급 시점, 중단 조건은 다시 묻습니다. 정보가 빠진 부분을 친절한 답변이나 빠른 응답으로 대신 채우지 마세요. 문의 결과가 불명확하면 추가 개인정보를 보내지 않습니다.

## 주체 확인표에서 미확인으로 남길 부분

등록 정보가 제시되면 해당 정보를 실제로 확인할 수 있는 공식 조회 경로를 요청합니다. 사진이나 캡처를 받았다는 사실과 공식 조회를 마친 사실을 구분하세요. 이 글은 특정 상대의 등록 여부나 신뢰도를 조사한 후기 또는 인증 목록이 아닙니다.

| 확인 대상 | 남길 기록 |
| --- | --- |
| 안내 주체 | 사이트 주소·상담 표시 이름·답변 시각 |
| 연락 경로 | 공개된 경로와 실제 연결된 대상의 차이 |
| 제시된 자격 | 공식 조회 경로·확인 결과 또는 미확인 |
| 지급 조건 | 최종 금액·시점·변경 답변 |

[상담 준비](/articles/consultation-preparation/)에 따라 개인정보를 최소화하고, 금액은 [수수료 계산](/articles/cashout-costs/)의 비교표로 따로 확인하세요.
