## 결제 완료와 상품 제공을 나누기

영수증은 결제 기록이고, 앱 안의 상품 표시나 사용 기록은 제공 여부에 관한 자료입니다. 두 화면을 대조하면 ‘주문이 없는 상태’와 ‘주문은 있는데 상품이 없는 상태’를 구분할 수 있습니다.

## 공식 지원 연락처 찾기

Play의 해당 앱 상세 페이지에서 개발자 연락처 또는 앱 지원 정보를 확인하세요. 검색 광고의 임의 연락처보다 설치한 앱의 공식 등록 정보를 우선 확인합니다. 화면과 메뉴는 기기에 따라 달라질 수 있어 원문 개발자 문의 도움말을 함께 보세요.

## 문의에 넣을 내용

| 항목 | 전달할 내용 |
| --- | --- |
| 대상 | 앱 이름·상품명·사용 계정 |
| 주문 | 구매 시각·주문번호·결제 금액 |
| 증상 | 상품이 안 보이는 위치와 발생 시점 |
| 요청 | 지급 상태 확인 또는 환불 검토 등 원하는 처리 |

로그인 비밀번호, 결제 인증번호, 기프트 카드 등록 코드는 문의 양식의 설명 자료와 구분해야 합니다. 공개 커뮤니티에는 식별 정보를 가리고 올리세요.

## 답변을 받은 뒤 확인할 것

앱 계정이 맞는지, 개발자가 확인한 주문이 원래 주문인지 살펴봅니다. 지급 완료 답변을 받았는데 화면이 다르면 실제 이용 기록을 다시 정리합니다. 환불을 원하는 경우에는 상품 미제공 문의와 환불 요청을 별개 항목으로 기록하세요.

동일한 자료를 시간 순으로 묶어 두면 여러 지원 창구에 같은 상황을 설명하기 쉬워집니다.
