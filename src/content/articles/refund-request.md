## 1. 취소하려는 주문 특정하기

구매 계정, 상품과 주문번호를 준비합니다. 다른 계정의 내역을 보고 있거나 서로 다른 주문을 혼동하면 신청 대상이 달라질 수 있습니다. 구매하지 않은 청구는 일반 취소 사유로 설명하기 전에 미승인 청구 경로를 확인하세요.

## 2. 정책 확인 후 요청하기

공식 도움말에서 환불 요청을 시작하세요. 웹 주문 내역에서는 대상 주문의 문제 신고를 선택하고 실제 상황에 맞는 이유를 제출하는 경로가 안내되어 있습니다. 상품별 정책이 다르므로 ‘결제했으니 무조건 환불’로 판단하지 않습니다.

## 3. 처리 단계 구분하기

| 단계 | 확인할 것 |
| --- | --- |
| 요청 접수 | 올바른 주문으로 요청했는가? |
| 승인 결정 | 환불 여부에 관한 답변이 왔는가? |
| 반영 확인 | 원래 결제 수단이나 명세서에 처리 결과가 반영되었는가? |

상태 확인 도움말에는 ‘취소됨’ 주문은 청구되지 않아 환불 내역이 표시되지 않을 수 있다고 설명되어 있습니다. 문자 하나만 보고 판단하지 말고 실제 주문 상태와 결제 내역을 같이 보세요.

## 4. 문의 기록 정리하기

요청 날짜, 주문번호, 접수 결과와 처리 상태를 한 곳에 보관합니다. 미제공 인앱 상품 등 개발자가 확인해야 할 사안은 해당 앱 지원 경로도 확인하세요. 계정 비밀번호를 대신 전달해 신청하도록 하는 방식은 피하세요.

구매 취소 기록이 있더라도 외부 거래 상대와의 정산 문제가 해결되었다는 뜻은 아닙니다. 각각 어떤 요청을 했는지 따로 적어 두세요.
